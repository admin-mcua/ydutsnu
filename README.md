# UNSTUDY — Review Lessons the Smart Way

_(formerly StudyMate)_

An AI-powered study web app where students upload notes/PDFs, turn them into
editable text, auto-generate flashcards, and convert those flashcards into
quizzes (multiple choice, situational, true/false, identification). Accounts
save everything automatically, and any set/quiz can be shared via a link.

## Features (completed)
- **Login & Sign up** (frontend). Sign up asks for **username, email, password, retype password**.
- **Login is by username + password** (not email). The **same login form works for admins** —
  admin credentials are detected automatically and redirect to the admin dashboard.
- **Show/hide password** eye icon on the right of every password field (login & signup).
- **Sign-up** has no robot or camera check (removed in v6). Device, ISP and location info is captured for the admin.
- **Upload PDF / notes → editable plain text** (PDF text extracted in-browser via PDF.js).
- **AI Flashcards**: choose **10–50 cards** (slider, default **30**), generated by Google Gemini.
  - If the **title is left blank**, the AI **auto-generates a title** from the content.
- **AI Quizzes**: after cards are made, pick question types
  (Multiple Choice / Situational / True or False / Identification) **and choose how many
  questions (10–50, slider)**, then the AI builds a quiz from the generated cards.
- **Interactive quiz player**: a **Start quiz** button, then questions appear **one by one**.
  After picking an answer it reveals the **correct answer + an explanation**, then a **Next**
  button advances. At the end a results screen appears and you can **replay every question you
  answered wrong** until they're all correct.
- **Accounts auto-save** every flashcard set and quiz.
- **Sharing**: each set/quiz has a public link to review cards or take the quiz.
- **Profile**: edit name, profile picture, birthday.
